## Major Changes

- Code mode moved to gRPC-based transports (`codemode/grpc`,
  `grpc_session_provider`, `grpc_transport`, `process_provider`, `stdio_host`)
  plus JSON-schema-to-TypeScript rendering and richer source/tool prompts.
- Multi-agent v2 coordination was expanded with role control, execution
  limiters and residency, thread spawn edges, identity keys, and the
  thread-spawn graph store.
- Responses handling gained connection retry, model cache refresh recovery,
  context-window IDs in responses metadata, attestation, and bounded tool-call
  metadata.
- Authentication gained workload identity, a managed auth backend, AWS/Bedrock
  credential refresh on 401 failures, and refresh-failure handling.
- Configuration gained managed cloud policy, external session/tool/memory
  imports, browser/computer-use keys, goals, memories settings, rollout
  budgets, remote sandbox config, and feature-file handling.
- Session and state moved to SQLite-backed persistence with thread history,
  migrations, projects, goals, memories jobs, log handlers, spawn edges, and
  queued submissions.
- Memories gained a full pipeline with control, extensions, prompts, storage,
  and workspace linking.
- MCP gained events, pagination, OAuth re-auth status, HTTP header helpers, and
  protocol discovery metrics.
- Plugin and rollout gained artifact operations, agent-plugin MCP config,
  marketplace installs, plugin metrics, canonicalization, lineage records,
  maintenance lock, and projection/session indexing.
- Tool and telemetry gained code-mode exec, async user messages, request
  permissions, goal specs, remote-sandbox delegation, test-sync, and many new
  telemetry event types.
- Execserver and network gained capability discovery, local filesystem
  forwarding, trace context, network-policy audits, environment network policy,
  and Windows proxy fallbacks.
