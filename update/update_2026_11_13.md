## Major Changes

- Sandbox expanded substantially with enforcement policies, deny-read targets,
  MXC launch/preparation/PSEC support, Windows integrity dependencies and
  protected metadata roots, Linux mount/glob handling, and updated Windows
  sandbox helpers. Obsolete Windows audit and world-writable metric files were
  removed upstream.
- MCP gained catalog and app UI resources, environment authority, approval and
  cancellation paths, OAuth credential refresh, startup readiness, header
  helpers, and broader tool-list/change handling.
- Configuration gained a stricter TOML schema and value validation layer,
  layered config loading semantics, permission and filesystem requirements,
  embedded network policy, project trust, model catalog/search settings, OTEL
  requirements, guardian elastic settings, marketplace/plugin requirements,
  and memory consolidation tiers.
- Execution server gained environment configuration reading, shell snapshots,
  pty/process-group handling, host config helpers, and richer unified-exec
  environment support.
- Model execution gained response diagnostics, attachment/image preparation,
  usage-limit handling, provider/auth recovery, workspace routing, model
  catalog/search metadata, and expanded executed-tool accounting.
- Tool execution gained Code Mode yielding, unified-exec process groups,
  shell snapshots, multi-environment copy, image budgets, user messaging,
  wait-for-environment, Windows safety rules, and critical-path timing.
- Session, state, and rollout gained thread history projection, realtime
  history wiring, disk-full/stability handling, rollout compression, memory
  store reclamation, SQLite busy/corruption recovery, turn attribution, and
  additional migrations.
- Authentication gained account grants, API-key storage, atomic credential
  commits, gateway device/login/logout flows, ChatGPT refresh progress,
  keyring fallback refresh, workload identity handling, workspace switching,
  and stronger stored-auth validation.
- Plugin support gained marketplace lifecycle upgrades, remote catalog sync,
  resource-bearing manifests, app MCP routing, install policy, and expanded
  activation-policy handling. The obsolete `plugin_extensions` files were
  removed upstream.
- Telemetry gained header helpers, OTLP logs/metrics/traces coverage,
  trace-context propagation, guardian/multi-agent events, runtime summaries,
  and many metric-name helpers.
- New support packages: `criticalpath` and `tooltiming` instrument turn/tool
  latency; `guardiancontext` assembles scoped Guardian review sections;
  `headershelper` builds OTEL/HTTP headers; `memorylock` coordinates external
  memory imports; `processgroup` and `ptyio` manage child processes and TTYs;
  `realtime` hosts realtime transport/history wiring; `runtimeauth` manages
  runtime credential registration; `shellparse` classifies PowerShell commands;
  and `stability` provides deterministic harness/scenario tooling.
- Code Mode protobuf definitions were refreshed and regenerated against the
  embedded module path.

```powershell

go vet ./...
```

`model`, `state`, and `tool` packages. An initial run hit one flaky live-proxy
assertion in `network`; the test and the complete package passed on rerun, and a
second full serialized run passed end to end.
